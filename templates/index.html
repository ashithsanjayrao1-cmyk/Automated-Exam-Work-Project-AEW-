About AEW

Automated Exam Work (AEW) is a flagship project by the Dept. of Master of Computer Application (MCA) to make exam organizations easier for colleges. This system solves these problems by using smart algorithms.

The admin only needs to upload the student list and available classrooms. The system arranges seating, making sure that nearby students do not have the same subject. It also quickly generates reports like seating plans, attendance sheets, and invigilation of duty lists. By using this application, colleges can conduct exams smoothly with fewer mistakes and less workload for staff.
